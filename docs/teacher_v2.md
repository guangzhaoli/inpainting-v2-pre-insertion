# Integrated Teacher v2

Teacher v2 combines the training and inference fixes identified by the teacher
audit. Five domain configurations are under `configs/teacher_v2/`. These are new
training runs; keep using the original experiment config with an old checkpoint.
The v2 rank, processor and conditioning contracts intentionally differ from v1.

## Behavior

- Attention uses the uv-pinned FlashAttention2 build in both Qwen-VL and DiT.
  `sdpa` remains an explicit alternative. See `training_optimizations.md` for
  the checkpoint-derived OPD builder and global-cursor resume contract.

- Frozen model weights and forward autocast use BF16. Trainable LoRA/geometry
  parameters and AdamW moments use FP32. Conversion happens before optimizer and
  DDP construction; optimizer restore converts saved moments to parameter dtype.
- Initialization is shared across ranks. Training RNG is reseeded after model
  preparation with `seed + 1000003 * rank`; resume restores checkpoint RNG after
  that initialization. The epoch sampler retains a separate deterministic seed.
- `aspect_pixels` uses an approximate 1 MP budget and rounds each dimension to
  multiples of 16. Legacy `fixed_pixels` remains unchanged for old checkpoints.
- Exact/morphology/augmented-box/asymmetric-box mask probabilities are
  20/20/30/30. The condition hole additionally includes a 16 px (accessory) or
  32 px (other domains) interaction margin. GT remains the supervision mask.
- Pixel supervision includes foreground LPIPS (0.5), distant-background L1
  (0.5), local detail LPIPS (0.25), boundary-band L1 (0.25), and reference DINO
  (0.2). Existing low-noise weighting/gating remains in place. Four detail crops
  are sampled from foreground occupancy and GT image gradients; they supervise
  aligned target details, not unaligned reference pixels.
- Human adds face-region DINO (0.2). OpenCV's bundled frontal-face detector runs
  in data workers; only faces with at least 80% overlap with the edit region
  qualify. Missing/occluded/profile faces may not be detected and contribute no
  face term. `train/face_pair_valid_fraction` reports this coverage. This reuses
  the local DINO encoder; it is not a dedicated face-recognition encoder.
- Reference identity and face terms are disabled for reference-dropped batches.
  Frozen perceptual encoders still backpropagate gradients to generated pixels.
- Category balancing visits every original sample and repeats smaller category
  pools to equalize their counts. An epoch can therefore be longer than v1.
  Every domain retains five epochs; no training examples are removed.
- LoRA uses rank/alpha 128, attention plus visual MLP adapters, and LR 5e-5.
  Reference CFG is mask-aware with delta clipping (ratio 1.0). Validation uses
  CFG 2.5 and 40 steps; independent CLI callers should pass those values too.
- Inference and periodic validation use `expanded_soft`. Primary output keeps
  the interaction area and soft transition; the strict-mask composite is saved
  as a comparison. A placement region must still accommodate the desired object.
- Validation selects fixed external cases with a seed that does not change
  across checkpoints. Ranks share the work and pad the final round to keep DDP
  forward counts equal. Metrics include raw background MAE and reference DINO
  cosine; they do not assume the source scene is a valid reconstruction GT.

The local model, DINOv2, VGG-LPIPS and external validation paths are generated by
`scripts/build_optimized_teacher_configs.py`. Validation pools are existing
external test sets; this change does not certify semantic identity disjointness
from training data. The scripts do not download models at training time.

## Environment and verification

Use uv, Python 3.12, and the checked-in `uv.lock`. Prepare missing dependencies
on a **new Inspire CPU Notebook**, as required by the workspace instructions:

```bash
uv sync --locked --link-mode symlink
```

On compute workers, use `uv sync --offline --locked` or the already prepared
shared `.venv`. `setup.sh` defaults to offline; its `--online` option is for the
CPU preparation machine only. All dependencies were prepared using
`guangzhao:v3` in project `具身世界模型`.

```bash
uv run --offline --no-sync python scripts/build_optimized_teacher_configs.py
OMP_NUM_THREADS=2 HF_HUB_OFFLINE=1 uv run --offline --no-sync pytest -q \
  tests/test_teacher_optimization.py tests/test_region_perceptual_loss.py \
  tests/test_validation_sampling.py tests/test_predict_preprocess_consistency.py
PYTHONPATH=. HF_HUB_OFFLINE=1 uv run --offline --no-sync python scripts/smoke_teacher_losses.py
```

The loss smoke uses real local LPIPS/DINO weights and checks finite input
gradients and frozen encoder gradients. Its synthetic 96 px tensors only test
the backward graph; it does not train Qwen or establish image quality.

## Launch

`scripts/run_teacher_v2.sh DOMAIN` accepts `accessory_jewelry`, `animal`,
`fashion_tryon`, `general_object`, or `human`. Use a separate job for each domain.
Select live Inspire resources and estimate throughput before submission. The
launcher supports 2/4/8 nodes (16/32/64 GPUs); it does not allocate resources.

For a four-node job, run on **every node**, with a distinct `MACHINE_RANK`:

```bash
NUM_MACHINES=4 NPROC_PER_NODE=8 TOTAL_PROCESSES=32 MACHINE_RANK=0 \
MAIN_PROCESS_IP=<master-ip> bash scripts/run_teacher_v2.sh human
```

Use `DRY_RUN=1` to inspect the command. Set `RESUME` only to a compatible v2
checkpoint. For standalone inference after training:

```bash
uv run --offline --no-sync python infer.py \
  --config configs/teacher_v2/human.yaml --device cuda:0 \
  --lora /absolute/path/to/v2/checkpoint \
  --src-image scene.png --src-mask placement.png \
  --ref-image reference.png --ref-mask reference_mask.png \
  --num-inference-steps 40 --true-cfg-scale 2.5 --output result.png
```

The configs use CPU device placeholders so preflight works on login/CPU nodes;
training uses Accelerate's device, and inference requires `--device cuda:0`.
Do not force a v1 rank-256 checkpoint into a v2 rank-128 config with a metadata
override. Old weights continue to use their original configs and processor.
